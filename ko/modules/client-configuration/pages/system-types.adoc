[[system-types]]
= 시스템 유형
:description: 클라이언트가 기본 역할 또는 추가 기능 역할을 할당하고 가상화 또는 컨테이너 빌드 호스트를 관리할 수 있도록 시스템 유형을 식별하십시오.
:revdate: 2026-08-10
:page-revdate: {revdate}

클라이언트는 시스템 유형에 따라 분류됩니다.
모든 클라이언트는 기본 시스템 유형과 추가 기능 시스템 유형을 모두 가질 수 있습니다.

모든 클라이언트의 기본 시스템 유형은 `Salt`입니다.

추가 기능 시스템 유형은 다음과 같습니다:

* `Virtualization Host`: 물리적 가상 호스트/하이퍼바이저(예: KVM)로 작동하는 클라이언트에 할당됩니다. 이 시스템 유형을 설정해야 일일 Taskomatic 작업이 시스템을 직접 쿼리하고(`libvirt`를 통해) menu:시스템[시스템 목록> 가상 시스템] 아래에 표시할 실행 중인 가상 머신을 인벤토리화하며 구독 매칭을 수행할 수 있습니다.
+
[NOTE]
====
물리적 가상화 호스트가 Salt 번들(`venv-salt-minion`)을 사용하여 관리되는 경우, SUSE 기반 운영 체제여야 하며 가상 머신 인벤토리 추적을 활성화하려면 호스트에 시스템 `libvirt-libs` 라이브러리가 설치되어 있어야 합니다. 자세한 내용은 xref:client-configuration:contact-methods-saltbundle.adoc#contact-methods-saltbundle-virt[Salt 번들 내 Salt \"virt\" 모듈의 가용성]을 참조하십시오.
====
* `Container Build Host`: 빌드 호스트로 작동하는 클라이언트에 할당됩니다.

.추가 기능 시스템 유형 조정
[role=procedure]
_____
. {productname} {webui}에서 menu:시스템[시스템 목록> 시스템 유형]으로 이동하십시오.

. 추가 기능 시스템 유형을 변경할 클라이언트를 선택하십시오.

. `Add-On System Type`을(를) 선택하십시오.

. btn:[시스템 유형 추가] 또는 btn:[시스템 유형 제거]를 클릭하십시오.
_____
