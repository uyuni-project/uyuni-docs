[[ubuntu-registration-overview]]
= Ubuntu 클라이언트 등록
:description: 클라이언트의 날짜와 시간이 귀하의 서버와 동기화되었는지 확인한 후, 활성화 키를 사용하여 Ubuntu 클라이언트를 귀하의 서버에 등록하십시오.
:revdate: 2020-08-27
:page-revdate: {revdate}

{productname} 서버에 {ubuntu} 클라이언트를 등록할 수 있습니다.
방법과 자세한 내용은 클라이언트의 운영 체제에 따라 다릅니다.

시작하기 전에 클라이언트의 날짜 및 시간이 {productname} 서버와 정확히 동기화되었는지 확인하십시오.

활성화 키도 생성해야 합니다.
활성화 키 생성에 대한 자세한 내용은 xref:client-configuration:activation-keys.adoc[]을 참조하십시오.
