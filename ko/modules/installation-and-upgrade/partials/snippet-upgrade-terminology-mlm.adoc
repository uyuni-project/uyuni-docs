== 용어

이 가이드는 다음 용어를 일관되게 사용합니다:

유지보수 업데이트::
동일한 버전의 유지보수 업데이트 간 이동(예: 5.2.0에서 5.2.1).
호스트 운영 체제를 업데이트한 다음 `mgradm upgrade` 또는 `mgrpxy upgrade`을(를) 실행하십시오.

업그레이드::
동일한 메이저 릴리스의 마이너 버전 간 이동(예: 5.1에서 5.2).
여기에는 호스트 운영 체제의 제품 마이그레이션도 포함됩니다.
업그레이드하기 전에 시스템을 현재 버전의 최신 유지보수 업데이트로 업데이트하고 실행 중인지 확인해야 합니다.

마이그레이션::
메이저 버전 간 이동(예: 4.3에서 5.x) 또는 RPM 기반 설치에서 컨테이너로 이동하는 것과 같은 배포 형태 변경.
마이그레이션하기 전에 소스 시스템을 최신 유지보수 업데이트로 업데이트하고 실행 중인지 확인해야 합니다.

유지보수 업데이트와 업그레이드는 모두 `mgradm upgrade` 또는 `mgrpxy upgrade`을(를) 사용하여 수행됩니다.
차이점은 실행하는 명령이 아니라 이동하는 대상입니다.
