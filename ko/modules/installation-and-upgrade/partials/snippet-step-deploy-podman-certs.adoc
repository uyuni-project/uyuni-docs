. 배포 {productname}.

+

[NOTE]
====
VM 이미지를 마이그레이션 대상으로 사용하는 경우, 마지막 단계에서 `mgradm migrate` 명령을 `mgradm install` 대신 실행하십시오.
====

+

SSL 인증서 종류(자체 서명 또는 제3자)에 따라 다음 명령 중 하나를 실행하십시오.
  `<FQDN>`을(를) {productname} 서버의 완전한 도메인 이름으로 교체하십시오:

+

--
* {productname}에서 제공하는 자체 서명 인증서를 사용하십시오:

+

[source,shell]
----
mgradm install <FQDN>
----

* 타사 SSL 인증서 플래그를 사용하여 SSL 인증서 임포트(필요한 인증서가 모두 포함되지 않은 경우 예제 조정 가능):

+

[source,shell]
----
mgradm install <FQDN> \
  --ssl-ca-intermediate <strings> \
  --ssl-ca-root <string> \
  --ssl-server-cert <string> \
  --ssl-server-key <string> \
  --ssl-db-ca-intermediate <strings> \
  --ssl-db-ca-root <string> \
  --ssl-db-cert <string> \
  --ssl-db-key <string>
----

[NOTE]
====
기본적으로 TFTP 서버 컨테이너는 서버에 배포되지 않습니다.
자동 설치(PXE 부팅/TFTP)의 경우 {productname} 프록시를 사용하는 것이 좋습니다.
프록시 없이 서버에서 직접 TFTP 서비스를 실행해야 하는 경우(권장하지 않음), `--tftpd-enable` 플래그를 `mgradm install`에 추가하십시오.
====

+

자세한 내용은 `mgradm install --help`을 참조하십시오.
