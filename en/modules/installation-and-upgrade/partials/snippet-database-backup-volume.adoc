= Database Backup Volume
:revdate: 2026-11-02
:page-revdate: {revdate}

During a {postgresql} database major version upgrade , `mgradm migration` or `mgradm upgrade` create a backup copy of the existing database.

For this purpose `mgradm` creates a backup directory named `_data_old` directly inside the database volume path at `/var/lib/containers/storage/volumes/var-pgsql/_data_old`.

[NOTE]
==== 
Because the `_data_old` directory is created on the same filesystem as the active database volume, it cannot be relocated to a separate storage volume during the upgrade process.
Ensure that the storage volume hosting `/var/lib/containers/storage/volumes/var-pgsql/` has at least twice the free space of your current database size, plus an extra 5–10% needed for running tasks during the upgrade, before starting `mgradm migration` or `mgradm upgrade`.

Once the migration or upgrade is complete and you have validated that the upgraded system is working as expected, you can safely delete the `_data_old` directory to reclaim disk space.
====
