[NOTE]
====
During an upgrade to version 5.2, `mgradm upgrade` only deploys the TFTP container on the server if TFTP was already enabled on the previous installation.
Using a {productname} Proxy is recommended for TFTP autoinstallation.
To force deploying the TFTP container directly on the server, append the `--tftpd-enable` flag to `mgradm upgrade`.
====
