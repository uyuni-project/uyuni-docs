[IMPORTANT]
====
Duplicate Foreign System Entries and Reverse DNS Converting a minion triggers proxy configuration generation behind the scenes. 
If the system is already a registered client, but generating the proxy configuration creates a duplicate entry of Foreign system type in {productname}, check the client's reverse DNS configuration.

The creation of a foreign system entry occurs when the system cannot be identified as a registered client. 
In this case, the root cause is an environment issue on the client host, such as incorrect DNS servers configured in `/etc/resolv.conf`, which prevents reverse DNS resolution from working correctly.

To avoid duplicate foreign entries, verify reverse DNS resolution on the client host before proceeding, and ensure the resolved FQDN matches exactly the registered client name in {productname}. 
If a duplicate Foreign entry has already been generated, correct the DNS server settings on the client, remove the duplicate foreign system entry from the {webui} Systems list, and regenerate the proxy configuration.
====
