== Terminology

This guide uses the following terms consistently:

Upgrade::
Moving to a newer {productname} release.
Update the host operating system packages, then run `mgradm upgrade` or `mgrpxy upgrade`.

Migration::
Changing the host operating system, for example from {leapmicro} 5.5 to {opensuse} {tumbleweed}, or changing the deployment form.

{productname} releases are rolling and have no separate maintenance-update concept.
