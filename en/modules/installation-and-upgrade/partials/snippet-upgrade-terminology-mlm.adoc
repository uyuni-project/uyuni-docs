== Terminology

This guide uses the following terms consistently:

Maintenance update::
Moving between maintenance updates of the same version, for example 5.2.0 to 5.2.1.
Update the host operating system, then run `mgradm upgrade` or `mgrpxy upgrade`.

Upgrade::
Moving between minor versions of the same major release, for example 5.1 to 5.2.
This also involves a product migration of the host operating system.

Migration::
Moving between major versions, for example 4.3 to 5.x, or changing the deployment form, such as moving from an RPM-based installation to containers.

A maintenance update and a product upgrade are both performed with `mgradm upgrade` or `mgrpxy upgrade`.
The difference is what you are moving between, not the command you run.
