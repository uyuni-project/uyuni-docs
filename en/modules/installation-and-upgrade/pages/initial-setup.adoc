[[initial-setup]]
= Initial Setup After Installation
:description: Connect a newly installed server to SUSE Customer Center and synchronize your first products
:revdate: 2026-10-21
:page-revdate: {revdate}

After installing {productname} {productnumber} Server, it does not yet contain any software channels.
Complete the steps in this section to connect the server to {scclongform} (SCC) and to synchronize the products you want to manage.

You need your {scclongform} organization credentials.
Find them in the {scclongform} under menu:Organization[Users > Organization Credentials], listed as `Mirroring credentials`.

[[proc-initial-setup]]
.Procedure: Connecting the server to {scclongform} and adding products
. Open a browser and go to the FQDN of your server.
. Log in with the username `admin` and the password you set during the deployment process.
. In the {webui}, navigate to menu:Admin[Setup Wizard].
. Optional: If your server must use an HTTP proxy to reach {scclongform}, select the btn:[HTTP Proxy] tab and enter the proxy hostname as `<hostname>:<port>`, and the credentials if required.
  Click btn:[Save].
. Select the btn:[Organization Credentials] tab.
  Click btn:[Add a new credential], enter the mirroring `Username` and `Password` from the {scclongform}, and click btn:[Save].
  When the credentials are valid, a green check-mark icon is shown.
. Select the btn:[Products] tab.
  The product list is downloaded from {scclongform} and populates automatically.
  This can take a few minutes.
  If nothing happens, click btn:[Refresh].
. Wait for the product list to finish loading.
. Select the check box next to each product you want to manage.
  Click the arrow next to a product to select individual modules and extensions.
. Click btn:[Add Products] to start synchronizing the product channels.

Synchronizing channels copies the software from {scclongform} to the server, and can take several hours depending on the products you chose.
Follow the progress on the btn:[Products] tab.
When a channel is fully synchronized, {productname} automatically generates the bootstrap repository for it, which you need to register clients.

For more information about the options on each tab, see xref:reference:admin/setup-wizard.adoc[].

When synchronization is complete, you can register a proxy or clients.
For more information, see xref:client-configuration:registration-overview.adoc[].
