[[ref-admin-menu]]
= Admin Menu
:description: Manage configuration settings through the Admin menu by creating and organizing users, organizations, and tasks. Use the setup wizard to help configure
:revdate: 2021-01-19
:page-revdate: {revdate}

The `Admin` menu provides access to features for managing {productname} configuration.
Configuration tasks include creating and managing organizations, users, and tasks.
You can also use the setup wizard to help configure {productname}.

[NOTE]
====
The `Admin` menu is only available if you are logged in to {productname} with an administrator account.
====
