[[ref-salt-remote-commands]]
= Remote Commands
:description: Use the Remote Commands section to run commands on one or more Salt clients by selecting individual targets or using search terms to find matching clients
:revdate: 2026-11-11
:page-revdate: {revdate}

The menu:Salt[Remote Commands] section allows you to perform remote commands on one or more of your Salt clients.
Remote commands allows you to issue commands to individual Salt clients, or to all clients that match a search term.

For more information about remote commands, see xref:administration:actions.adoc[].

[NOTE]
====
Administrators can disable remote commands globally.
In that case, this page is not available.
For more information, see xref:administration:actions.adoc#disable-remote-commands[].
====
