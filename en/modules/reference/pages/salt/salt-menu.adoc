= Salt Menu
:description: Manage Salt clients by using the Salt menu to run remote commands or set up state catalogs for configuring and maintaining systems.
:revdate: 2022-01-13
:page-revdate: {revdate}

The `Salt` section displays details of your Salt clients.
You can use this menu to perform remote commands or define a state catalog for your Salt clients.

For more information about using Salt with {productname}, see xref:specialized-guides:salt/salt-overview.adoc[].
