= Audit Menu
:description: Manage security updates on clients using the Audit menu to find and update systems with the latest CVE patches and check subscription matching
:revdate: 2020-09-11
:page-revdate: {revdate}

The `Audit` menu provides access to features for managing security updates on your clients.
Audit tasks include finding and updating clients with the latest CVE patches, subscription matching, and managing OpenSCAP scans.
