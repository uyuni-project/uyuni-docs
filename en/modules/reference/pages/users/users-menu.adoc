[[ref-users-menu]]
= Users Menu
:description: Manage user accounts and permissions through the Users menu by creating new users, editing user details, assigning roles, and modifying system groups.
:revdate: 2021-01-19
:page-revdate: {revdate}

The `Users` menu provides access to grant and edit permissions for those who administer your system groups.
You can create new users, and edit user details, roles, and system groups.

[NOTE]
====
The `Users` menu is only available if you are signed in to {productname} with an administrator account.
====

For more information about managing users, see xref:administration:users.adoc[].
