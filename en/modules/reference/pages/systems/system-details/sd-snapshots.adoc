[[ref-systems-sd-snapshots]]
= Btrfs Snapshots
:description: View Btrfs snapshots for a transactional system and refresh the snapshot information
:revdate: 2026-10-07
:page-revdate: {revdate}

The menu:Systems[Btrfs Snapshots] tab is available for transactional systems.
It lists the most recent snapshots reported by `snapper` and identifies the active and default snapshots.

Click btn:[Refresh Snapshots] to schedule an update of the snapshot information.
The refresh action appears in the system events.
{productname} also automatically refreshes snapshot information after a transactional action reports changes.
For when transactional changes become active, see xref:client-configuration:transactional-systems.adoc[].
