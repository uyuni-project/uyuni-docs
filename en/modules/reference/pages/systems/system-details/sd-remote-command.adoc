= Remote Command
:description: Use the Remote Command section in the Systems menu to execute commands on a selected client from a remote location after properly configuring the system
:revdate: 2026-11-11
:page-revdate: {revdate}

The menu:Systems[Details > Remote Command] section allows you to run commands remotely on the selected client.

Before doing so, you must first configure the system to accept such commands.
For more information about using remote commands, see xref:administration:actions.adoc[].

On transactional systems, select `Use transactional update` to run a command transactionally.
Leave the option unselected to run the command on the live system.
For more information, see xref:client-configuration:transactional-systems.adoc[].

[NOTE]
====
Administrators can disable remote commands globally.
In that case, this page is not available.
For more information, see xref:administration:actions.adoc#disable-remote-commands[].
====
