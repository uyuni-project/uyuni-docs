[[troubleshooting-reg-from-webui-fails-no-errors]]
= 使用 {webui} 进行的注册故障排查失败，且未显示任何错误。
:description: 当从 Web UI 注册失败且未显示任何错误时，请检查 /var/log/salt-ssh.log 中的本地日志文件以查找错误。
:revdate: 2022-10-18
:page-revdate: {revdate}

在 {webui} 进行初始注册时，所有 Salt 客户端均使用 Salt SSH。

由其性质决定，Salt SSH 客户端不会向服务器回报错误。

不过，Salt SSH 客户端会将日志保存在本地的 `/var/log/salt-ssh.log`，可以用于检查错误。
