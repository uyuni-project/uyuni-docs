[[ubuntu-registration-overview]]
= Ubuntu 客户端注册
:description: 在确保客户端的日期和时间与服务器同步后，使用激活密钥将 Ubuntu 客户端注册到您的服务器。
:revdate: 2020-08-27
:page-revdate: {revdate}

您可以将 {ubuntu} 客户端注册到您的 {productname} 服务器。
方法和细节视客户端的操作系统而异。

开始前，请确保客户端的日期和时间已与 {productname} 服务器正确同步。

您必须已创建激活密钥。
有关创建激活密钥的更多信息，请参见 xref:client-configuration:activation-keys.adoc[]。
