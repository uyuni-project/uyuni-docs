[[oes-registration-overview]]
= {oes} 客户端注册
:description: 通过使用激活密钥以及正确的日期和时间设置，将 Open Enterprise Server 客户端注册到您的服务器。
:revdate: 2026-05-05
:page-revdate: {revdate}

您可以将 {oes} 客户端注册到您的 {productname} 服务器。
方法和细节视客户端的操作系统而异。

开始前，请确保客户端的日期和时间已与 {productname} 服务器正确同步。

您必须已创建激活密钥。

有关创建激活密钥的更多信息，请参见 xref:client-configuration:activation-keys.adoc[]。
