[[client-cfg-overview]]
= 客户端配置指南
:description: 通过执行包括手动或自动注册客户端以及为受支持的 Linux 系统配置相应参数的步骤来配置客户端。
:revdate: 2025-05-21
:page-revdate: {revdate}

// HTML Publication date 
**出版日期:** {docdate}

== 首选项


安装 {productname} 后，第一步是注册客户端。管理这些客户端将是您工作流程的关键部分。

{productname} 支持 {sle} 和其他 Linux 发行套件，并兼容多种硬件选项。

有关支持的客户端和功能的完整列表，请参阅 xref:client-configuration:supported-features.adoc[支持的客户端和功能]。

本指南将介绍手动和自动注册及配置客户端的过程。
