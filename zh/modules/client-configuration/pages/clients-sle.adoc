= 注册 {sle} 客户端
:description: 通过添加软件频道并在注册前进行同步来注册 SUSE Linux Enterprise 客户端
:revdate: 2026-08-24

本节包含有关注册运行 {sle} 操作系统的客户端的信息。

请使用本章中的说明来准备所有 {sle} 产品，包括：

* {sles} 用于 SAP
* {sle} 桌面
* {sle}
* {sle} 实时

您也可以按照这些说明准备较旧的 {sle} 版本和服务包。

----
mgr-sync list channels [-c]

== 管理 GPG 密钥

客户端使用 GPG 密钥在安装软件包之前检查其真实性。
只有受信任的软件包才能在客户端上安装。

[IMPORTANT]
====
信任 GPG 密钥对客户端的安全性至关重要。
决定需要哪些密钥并可以信任哪些密钥是管理员的任务。
由于在 GPG 密钥未被信任时无法使用软件通道，因此是否将通道分配给客户端取决于是否信任该密钥。
====

有关 GPG 密钥的更多信息，请参见 xref:client-configuration:gpg-keys.adoc[]。

[NOTE]
====
* 请对 {sles}{nbsp}15 和 {sles}{nbsp}12 客户端使用相同的 GPG 密钥。
  正确的密钥称为 `sle12-gpg-pubkey-39db7c82.key`。

* {sles}{nbsp}16 个客户端使用不同的 GPG 密钥。
  正确的密钥称为 `suse16-gpg-pubkey-09d9ea69.key`.
====


endif::[]



== Root 访问权限

诸如 {sle} 16 之类的操作系统可以在不启用 root 访问权限的情况下进行安装（例如，在使用 Agama 且仅创建一个普通用户时）。
要接入这些客户端，您必须编辑客户端系统上的 `sudoers` 文件。

有关配置 `sudo` 进行非 root 接入的详细说明，请参阅 xref:client-configuration:registration-sudo.adoc[]。
