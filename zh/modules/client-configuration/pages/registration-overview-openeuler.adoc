[[openeuler-registration-overview]]
= {openeuler} 客户端注册
:description: 使用激活密钥将 openEuler 客户端注册到您的服务器，并确保在开始操作前，所有客户端的日期和时间都已与服务器同步。
:revdate: 2025-06-30
:page-revdate: {revdate}

ifeval::[{mlm-content} == true]

[IMPORTANT]
====
在 {productname} 中，{openeuler} 的支持作为技术预览可用。
====
endif::[]

您可以将 {openeuler} 客户端注册到您的 {productname} 服务器。
方法和细节视客户端的操作系统而异。

开始前，请确保客户端的日期和时间已与 {productname} 服务器正确同步。

您必须已创建激活密钥。
有关创建激活密钥的更多信息，请参见 xref:client-configuration:activation-keys.adoc[]。
