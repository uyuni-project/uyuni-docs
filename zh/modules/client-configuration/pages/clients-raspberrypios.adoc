:description: 通过准备系统、添加软件渠道以及使用激活密钥，将 Raspberry Pi OS 客户端注册到服务器。

可以通过启动 {raspberrypios} 客户端来执行初始状态的运行以及控制文件的更新。

== 准备注册


在将 {raspberrypios} 客户端注册到 {productname} 服务器之前，您需要完成一些准备工作：

* 确保 DNS 配置正确，并为客户端提供条目。
  或者，您可以在 {productname} 服务器和客户端上配置 `/etc/hosts` 文件，添加适当的条目。
* 注册前，客户端的日期和时间必须已与 {productname} 服务器同步。

== 创建激活密钥

您需要创建与您的 {raspberrypios} 通道关联的激活密钥。

有关激活密钥的更多信息，请参见 xref:client-configuration:activation-keys.adoc[]。




== 管理 GPG 密钥

客户端使用 GPG 密钥在安装软件包之前检查其真实性。
只有受信任的软件包才能在客户端上安装。

[IMPORTANT]
====
信任 GPG 密钥对客户端的安全性至关重要。
决定需要哪些密钥并可以信任哪些密钥是管理员的任务。
由于在 GPG 密钥未被信任时无法使用软件通道，因此是否将通道分配给客户端取决于是否信任该密钥。
====

有关 GPG 密钥的更多信息，请参见 xref:client-configuration:gpg-keys.adoc[]。

[NOTE]
====
{raspberrypios} 客户端可能需要安装多个 GPG 密钥。
====

在同步第三方 {raspberrypios} 储存库时，您需要在服务器上导入适当的 GPG 密钥。
如果缺少 GPG 密钥，同步将失败。

对于 {raspberrypios} 储存库，仅元数据被签名。
因此，不需要为软件通道导入 GPG 密钥。
软件包不会被 {productname} 重新签名。

要查看已导入 {productname} 服务器的 GPG 密钥，请运行以下命令：

----
mgrctl exec -- gpg --homedir /var/lib/spacewalk/gpgdir --list-keys
----

要导入新的 GPG 密钥，请运行以下命令：

----
mgradm gpg add <filename>.gpg
----



== Root 访问权限

默认会为 {raspberrypios} 上的 root 用户禁用 SSH 访问权限。
要以普通用户身份完成接入，您必须编辑客户端系统上的 `sudoers` 文件。

有关配置 `sudo` 以进行非 root 用户接入的详细说明，请参阅 xref:client-configuration:registration-sudo.adoc[]。
