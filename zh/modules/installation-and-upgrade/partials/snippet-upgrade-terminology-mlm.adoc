== 术语

本指南始终使用以下术语：

维护更新::
在同一版本的维护更新之间切换，例如从 5.2.0 到 5.2.1。
更新主机操作系统，然后运行 `mgradm upgrade` 或 `mgrpxy upgrade`。

升级::
在同一主版本的次版本之间切换，例如从 5.1 到 5.2。
这也涉及主机操作系统的产品迁移。
升级前，您必须将系统更新至当前版本的最新可用维护更新，并确保其正在运行。

迁移::
在主版本之间切换，例如从 4.3 到 5.x，或更改部署方式，例如从基于 RPM 的安装迁移到容器。
迁移前，您必须将源系统更新至最新可用的维护更新，并确保其正在运行。

维护更新和升级均通过 `mgradm upgrade` 或 `mgrpxy upgrade` 执行。
区别在于您所切换的内容，而不是您运行的命令。
