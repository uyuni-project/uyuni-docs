[[supported-features-sles]]
= {slsa}および{leap}でサポートされている機能
:description: SUSE Linux EnterpriseおよびopenSUSE Leapクライアントで利用可能な機能、利用できない機能、および検討中の機能を確認してください。
:revdate: 2024-05-10
:page-revdate: {revdate}


この表には、{suse}および{leap}クライアント上でのさまざまな機能の利用可能性が示されています。
この表は、{sle}SAP用の{slsa}、{sleda}、{sles}、およびHPC用の{sles}を含むオペレーティングシステムのすべてのバリアントをカバーしています。

[IMPORTANT]
====
クライアントで実行されているオペレーティングシステムは、それを提供する組織によってサポートされています。 +
{sle}は{suse}によってサポートされています。 +
{leap}は{opensuse}コミュニティによってサポートされています。
====

この表のアイコンの意味は次のとおりです。

* {check}: 機能は使用可能です
* {cross}: 機能は使用できません
* {question}: 機能は検討中であり、後日利用可能になるかどうかは未定です
