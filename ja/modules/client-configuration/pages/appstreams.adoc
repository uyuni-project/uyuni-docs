= AppStreamモジュール
:description: AppStream モジュールを管理して、AppStream チャネルにサブスクライブしているクライアントが利用可能なパッケージを制御します。
:revdate: 2024-05-03
:page-revdate: {revdate}

AppStreamチャンネルにサブスクライブしているクライアントを管理する場合、{productname}により、現在有効になっている一連のAppStreamモジュールに応じて、クライアントで利用可能なパッケージがフィルタリングされます。
