[[supported-features-ubuntu]]
= サポートされている{ubuntu}機能
:description: このページは、Ubuntuのどの機能が利用可能か、利用できないか、または将来サポートが検討されているかを示しており、ユーザーが利用可能な機能を理解するのに役立ちます。
:revdate: 2026-07-27
:page-revdate: {revdate}


この表には、{ubuntu}クライアントのさまざまな機能の使用可否がリストされています。

[IMPORTANT]
====
クライアントで実行しているオペレーティングシステムは、オペレーティングシステムを提供している組織によってサポートされています。{ubuntu}はCanonicalでサポートされています。
====

この表のアイコンの意味は次のとおりです。

* {check}: 機能は使用可能です
* {cross}: 機能は使用できません
* {question}: 機能は検討中であり、後日利用可能になるかどうかは未定です
