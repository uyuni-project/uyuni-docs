[[system-types]]
= システムの種類
:description: クライアントにベースロールまたはアドオンロールを割り当て、仮想化またはコンテナビルドホストを管理するためのシステムタイプを特定します。
:revdate: 2026-08-10
:page-revdate: {revdate}

クライアントはシステムの種類によって分類されます。
すべてのクライアントには、ベースシステムの種類とアドオンシステムの種類の両方を割り当てることができます。

ベースシステムの種類は、すべてのクライアントで`Salt`です。

アドオンシステムタイプには以下が含まれます。

* `Virtualization Host`:物理仮想ホスト/ハイパーバイザー（KVMなど）として動作するクライアントに割り当てられます。このシステムタイプを設定すると、日次のTaskomaticジョブがシステムを直接（`libvirt`経由で）クエリし、menu:Systems[System List > Virtual Systems]の下に表示するための実行中の仮想マシンをインベントリ化し、サブスクリプションを照合できるようになります。
+
[NOTE]
====
物理仮想化ホストがSalt Bundle（`venv-salt-minion`）を使用して管理されている場合、SUSEベースのオペレーティングシステムである必要があり、仮想マシンのインベントリ追跡を有効にするには、ホストにシステム`libvirt-libs`ライブラリがインストールされている必要があります。詳細については、xref:client-configuration:contact-methods-saltbundle.adoc#contact-methods-saltbundle-virt[Availability of Salt's \"virt\" module inside the Salt Bundle]を参照してください。
====
* `Container Build Host`:ビルドホストとして動作するクライアントに割り当てられます。

.アドオンシステムタイプを変更します。
[role=procedure]
_____
. {productname} {webui}で、menu:Systems[System List > System Types]に移動します。

. アドオンシステムタイプを変更するクライアントにチェックを入れます。

. `Add-On System Type`を選択します。

. btn:[システムタイプの追加]またはbtn:[システムタイプの削除]のいずれかをクリックします。
_____
