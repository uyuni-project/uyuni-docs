== 用語集

本ガイドでは、以下の用語を一貫して使用します。

アップグレード::
より新しい {productname} リリースへ移行します。
ホストオペレーティングシステムのパッケージを更新してから、`mgradm upgrade` または `mgrpxy upgrade` を実行してください。

移行::
ホストオペレーティングシステムの変更（例: {leapmicro} 5.5 から {opensuse} {tumbleweed} への変更）、またはデプロイメント形式の変更。

{productname} リリースはローリング形式であり、個別のメンテナンス更新という概念はありません。
