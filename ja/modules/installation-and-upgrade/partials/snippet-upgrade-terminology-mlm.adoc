== 用語集

本ガイドでは、以下の用語を一貫して使用します。

保守更新::
同じバージョンの保守更新間での移行（例: 5.2.0 から 5.2.1）。
ホストオペレーティングシステムを更新してから、`mgradm upgrade` または `mgrpxy upgrade` を実行してください。

アップグレード::
同じメジャーリリースのマイナーバージョン間での移行（例: 5.1 から 5.2）。
これには、ホストオペレーティングシステムの製品移行も含まれます。
アップグレードの前に、システムを現在のバージョンの最新の保守更新に更新し、それが実行されていることを確認する必要があります。

移行::
メジャーバージョン間での移行（例: 4.3 から 5.x）、または RPM ベースのインストールからコンテナへの移行など、デプロイメント形式の変更。
移行の前に、ソースシステムを最新の保守更新に更新し、それが実行されていることを確認する必要があります。

保守更新とアップグレードは、どちらも `mgradm upgrade` または `mgrpxy upgrade` を使用して実行されます。
違いは実行するコマンドではなく、移行元と移行先の関係です。
