. デプロイする {productname}。

+

[NOTE]
====
VMイメージを移行先として使用する場合は、最後のステップとして、`mgradm migrate`の代わりに`mgradm install`コマンドを実行してください。
====

+

SSL証明書の種類（自己署名またはサードパーティ）に応じて、次のコマンドのいずれかを実行してください。
  `<FQDN>`を{productname}サーバーの完全修飾ドメイン名に置き換えてください：

+

--
* が提供する自己署名証明書を使用する場合{productname}：

+

[source,shell]
----
mgradm install <FQDN>
----

* サードパーティSSL証明書フラグを使用してSSL証明書をインポートする場合(これらすべての証明書が必要なわけではない場合は例を調整可能):

+

[source,shell]
----
mgradm install <FQDN> \
  --ssl-ca-intermediate <strings> \
  --ssl-ca-root <string> \
  --ssl-server-cert <string> \
  --ssl-server-key <string> \
  --ssl-db-ca-intermediate <strings> \
  --ssl-db-ca-root <string> \
  --ssl-db-cert <string> \
  --ssl-db-key <string>
----

[NOTE]
====
デフォルトでは、TFTPサーバーコンテナはサーバー上にデプロイされません。
自動インストール（PXE/TFTP）には、{productname}プロキシの使用が推奨されます。
プロキシを使用せずにサーバー上で直接TFTPサービスを実行する必要がある場合（非推奨）、`--tftpd-enable`フラグを`mgradm install`に追加してください。
====

+

詳細については、`mgradm install --help`を参照してください。
